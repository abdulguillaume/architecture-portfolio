## Preview

Open `index.html`, or:

```powershell
cd portfolio
python -m http.server 5500
```

Visit `http://localhost:5500`.

## Publish (GitHub Pages)

1. Repo name: `YOUR_USERNAME.github.io`
2. Push **contents** of this `portfolio/` folder to the repo root
3. Settings → Pages → branch `main` / root
